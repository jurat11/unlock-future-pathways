# 🎨 UNLOCK Website Constructor - Complete Guide

## 🚀 Overview

Your website has been transformed into a powerful, fully editable constructor similar to Tilda or Webflow. Every element can now be edited, styled, and rearranged without any coding knowledge.

## ✨ Features Implemented

### 🖱️ **Edit Mode Controls**
- **Toggle Edit Mode**: Click "Editing: OFF/ON" button (or press `Ctrl+E`)
- **Emergency Reset**: Red reset button if editing gets stuck
- **Auto-save**: All changes are automatically saved to browser storage

### 📝 **Text Editing**
- **Click any text** in edit mode to modify it directly
- **Inline editing** with real-time preview
- **Multi-language support** with translation overrides
- **Rich text formatting** preserved

### 🖼️ **Image Editing**
- **Click any image** in edit mode to:
  - Upload new images from your computer
  - Use image URLs from the internet
  - Resize (width/height in pixels)
  - Change image fit (cover, contain, fill, etc.)
  - Edit alt text for accessibility
  - Reset to original image

### 🎥 **Video Editing**
- **YouTube Videos**: Paste YouTube URLs for instant embedding
- **Direct Videos**: Upload video files or use video URLs
- **Custom Thumbnails**: Set custom preview images
- **Video Settings**: Control autoplay, controls, muted state
- **Responsive Sizing**: Adjust dimensions for different screens

### 🎨 **Section Editing**
- **Visual Section Controls**: Hover over sections to see edit options
- **Move Sections**: Use up/down arrows to reorder
- **Style Sections**: Edit background, padding, margins, borders
- **Copy Sections**: Duplicate sections to other parts of the page
- **Delete Sections**: Remove unwanted sections
- **Hide/Show**: Toggle section visibility

### 🖌️ **Global Theme Editor**
- **Color Palette**: Change primary, secondary, and accent colors
- **Typography**: Modify fonts, sizes, weights, and line heights
- **Spacing**: Adjust container widths, padding, and margins
- **Layout Properties**: Edit border radius, shadows, and effects
- **Preset Themes**: Apply pre-designed color schemes
- **Export/Import**: Save themes as JSON files
- **Live Preview**: See changes immediately

### 🧩 **Component Library**
- **Pre-built Components**: Hero sections, contact forms, team sections, galleries
- **Categories**: Layout, Content, Media, Forms, Social components
- **Custom HTML**: Add your own HTML code with Tailwind CSS
- **One-click Insert**: Add components instantly to your page
- **Component History**: View and manage recently added components

### 🎯 **Drag & Drop**
- **Visual Drag Handles**: Appear on hover in edit mode
- **Drop Zones**: Highlighted areas show where you can drop sections
- **Smooth Animations**: Visual feedback during drag operations
- **Auto-save Order**: Section order is automatically saved

### 👀 **Preview Mode**
- **Device Preview**: Test on desktop, tablet, and mobile
- **Full Preview**: Open in new window for complete testing
- **Export HTML**: Download clean HTML without edit controls
- **Responsive Testing**: See how your site looks on different screen sizes

### ↩️ **Undo/Redo System**
- **Keyboard Shortcuts**: `Ctrl+Z` to undo, `Ctrl+Y` to redo
- **Visual Controls**: Undo/redo buttons in the toolbar
- **Change History**: View recent changes and reset if needed
- **Smart Tracking**: Automatically tracks text, image, style, and layout changes

## 🛠️ **How to Use**

### Getting Started
1. **Enable Edit Mode**: Click the "Editing: OFF" button in the bottom-right corner
2. **Look for Orange Outlines**: Editable elements will have orange borders
3. **Click to Edit**: Click on any outlined element to start editing

### Text Editing
1. **Click any text** to start editing inline
2. **Type directly** to replace content
3. **Click outside** or press Escape to finish editing

### Image Editing
1. **Click any image** in edit mode
2. **Use the dialog** to upload new images or enter URLs
3. **Adjust settings** like size and fit
4. **Apply changes** to see them live

### Adding New Sections
1. **Click "Components"** in the toolbar
2. **Browse categories** or use custom HTML
3. **Click "Insert Component"** to add to your page
4. **Edit the new section** as needed

### Styling Your Site
1. **Click "Theme Editor"** for global changes
2. **Edit individual sections** by clicking their edit icons
3. **Use drag & drop** to rearrange sections
4. **Preview changes** before publishing

### Testing Your Site
1. **Click "Preview"** to test your site
2. **Switch between devices** to check responsiveness
3. **Export HTML** for deployment
4. **Use undo/redo** if you need to revert changes

## ⚡ **Keyboard Shortcuts**

- `Ctrl+E` (or `Cmd+E`): Toggle edit mode
- `Escape`: Exit edit mode
- `Ctrl+Z` (or `Cmd+Z`): Undo last change
- `Ctrl+Y` (or `Cmd+Y`): Redo last change
- `Ctrl+Shift+Z` (or `Cmd+Shift+Z`): Alternative redo

## 💾 **Data Storage**

All your changes are automatically saved to your browser's local storage:
- **Text changes**: Stored with unique keys per element
- **Image uploads**: Converted to base64 and stored locally
- **Style changes**: Saved as JSON objects
- **Component additions**: Tracked with timestamps
- **Section order**: Automatically maintained

## 🔄 **Import/Export**

### Exporting Your Work
1. **Text Content**: Use "Export/Import" in toolbar for text changes
2. **Theme Settings**: Export themes as JSON files from Theme Editor
3. **Complete Site**: Use "Export" in Preview mode for clean HTML
4. **Component Library**: Saved components are tracked for reuse

### Importing Content
1. **Text Data**: Import JSON files through the toolbar
2. **Themes**: Load theme JSON files in Theme Editor
3. **Components**: Paste HTML code in Custom HTML tab

## 🚨 **Troubleshooting**

### If Edit Mode Gets Stuck
1. Click the **red "Reset" button** in the toolbar
2. Refresh the page if needed
3. Use the Emergency Reset in Preview mode

### If Changes Don't Save
1. Check if cookies/localStorage are enabled
2. Clear browser cache and try again
3. Export your changes before refreshing

### If Drag & Drop Doesn't Work
1. Make sure you're in edit mode
2. Look for the drag handles on section hover
3. Try refreshing the page

### If Components Don't Load
1. Check browser console for errors
2. Disable ad blockers temporarily
3. Try using a different browser
